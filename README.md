# Unity Menu Template

Template de menu desenvolvido em Unity, criado para servir como base reutilizável em projetos 2D e 3D.

O projeto reúne os sistemas mais comuns de navegação e gerenciamento de progresso, permitindo iniciar rapidamente um novo jogo sem a necessidade de implementar toda a estrutura de menus novamente.

---

## Funcionalidades

- ✅ Main Menu
- ✅ Continue Game
- ✅ New Game
- ✅ Level Select
- ✅ Pause Menu
- ✅ Settings Menu
- ✅ Credits
- ✅ Scene Transition
- ✅ Save Game
- ✅ Load Game
- ✅ Delete Save
- ✅ 2 Save Slots independentes

---

## Tecnologias

- Unity
- C#
- UI Toolkit / Unity UI
- Scene Management
- Git

---

## Estrutura do Projeto

O template foi desenvolvido com foco em organização e reutilização.

Os principais sistemas são:

- Menu Manager
- Save System
- Level Selection
- Scene Transition
- Pause Manager
- Settings Manager

Cada sistema é independente, facilitando sua adaptação para diferentes tipos de jogos.

---

## Objetivo

Este projeto foi desenvolvido para ser utilizado como ponto de partida em novos projetos Unity, reduzindo o tempo gasto com a criação de menus e gerenciamento de progresso.

Pode ser utilizado tanto em jogos 2D quanto 3D.
